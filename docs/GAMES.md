# Old Games Hub

Old Games Hub - простое графическое меню для старых Windows-игр.

Пользователь видит простые действия:

- `Играть / открыть Lutris`
- `Добавить NFS Most Wanted 2005`
- `Добавить S.T.A.L.K.E.R.`
- `Открыть папку игр`
- `Настройки игр`
- `Починить запуск игры`

В интерфейсе специально не используются слова `wineprefix`, `runner`, `DXVK`, `Proton`. Эти детали остаются внутри скриптов.

## Как добавить NFS Most Wanted 2005

1. Открой ярлык `Игры`.
2. Нажми `Добавить NFS Most Wanted 2005`.
3. Выбери `.exe` файл игры или установщик.
4. После добавления появится ярлык `NFS Most Wanted 2005` на рабочем столе.
5. Если игра не запускается, снова открой `Игры` и выбери `Починить запуск игры`.

## Как добавить S.T.A.L.K.E.R.

1. Открой ярлык `Игры`.
2. Нажми `Добавить S.T.A.L.K.E.R.`.
3. Выбери `.exe` файл игры или установщик.
4. Запускай игру с созданного ярлыка.

## Что делает кнопка ремонта

Кнопка `Починить запуск игры`:

- останавливает зависшие игровые процессы;
- обновляет игровую среду;
- ставит частые компоненты для старых игр: шрифты, Visual C++ 2005/2008, DirectX 9 компоненты.

Нужен интернет. Если интернета нет, часть восстановления может не выполниться.

## DXVK

DXVK может ускорить DirectX 9/10/11 игры, но только если видеокарта поддерживает Vulkan.

Для очень старых ноутбуков:

- сначала пробуй обычный запуск;
- если игра работает медленно, проверь Vulkan;
- если Vulkan не поддерживается, DXVK не использовать.

Проверка Vulkan для разработчика:

```bash
vulkaninfo --summary
```

Если `vulkaninfo` не работает, DXVK почти наверняка не подходит.

## Где лежат игры

Папка игр:

```text
~/Игры/Old Games
```

Техническая папка Wine:

```text
~/.local/share/homeplay-games/default
```

Обычному пользователю не нужно открывать техническую папку.
